HTTP PROTOCOL
***********************************************************************************************

HTTP stands for Hypertext transfer protocol
It is a communication protocol used to transfer data over web.
It works on client server architecture.
It is a stateless protocol. (request-response protocol)
Port used for HTTP is port no. 80 and and for HTTPS is port no. is 443.
HTTPS is a secure version. It uses SSL/TLS encyption.


HTTP Working:
=============

1. Client(browser) sends an HTTP request to a server.
2. The server processes the request and send back an HTTP response.
3.  Browser displays the page to user.

___Steps:___

1. User enters URL:
You type https://example.com in your browser.

2. Browser connects to server:
Server sends its SSL/TLS certificate to the browser.
The certificate includes the public key and server identity.

3. Browser verifies certificate:
Checks if the certificate is from a trusted authority (CA).
If valid, it creates a session key (for encryption).

4. Key Exchange:
Browser encrypts the session key with the server's public key.
Only the server can decrypt it using its private key.

5. Secure connection established:
All data (login info, payment, etc.) is now encrypted and safe.


HTTP Methods:
=============

1. GET --> To retreives data
2. POST --> Submits data
3. PUT --> Update existing data
4. DELETE --> Remove data
5. HEAD --> Like GET but returns Headers.
6. PATCH --> Partially update data.


HTTP Status Code:
=================

200 --> Success
301 --> Moved Permanently (Redirected)
400 --> Bad Request
404 --> Not found
500 --> Internal server error
