Socket Steps:
*********************************************************************************************

1. Create server socket.
serv_fd = socket(AF_INET, SOCK_STREAM, 0);

2. Assign socket address (IP addr + port no). 
ret = bind(serv_fd, &serv_addr, sizeof(serv_addr));

3. Listen to the server socket. 
listen(serv_fd, 5);

4. Create Client Socket.
cli_fd = socket(AF_INET, SOCK_STREAM, 0);

5. Connect to the server.
ret = connect(cli_fd, &serv_addr, sizeof(serv_addr));

6. Accept client connection (blocked until client connects).
cli_fd = accept(serv_fd, &cli_addr, sizeof(cli_addr));

7. Send data to server.
write(cli_fd, buf, size);

8. Read data from client.
read(cli_fd, buf, size);

9. Send data to client.
write(cli_fd, buf, size);

10. Read data from server.
read(cli_fd, buf, size);

11. Close client socket.
close(cli_fd);

12. Close client socket.
close(cli_fd);

13. Shutdown the server socket.
shutdown(serv_fd, SHUT_RDWR);
